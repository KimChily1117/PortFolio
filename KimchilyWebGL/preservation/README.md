# 보존한 Android 기준 버전

원본 작업공간: `E:\task\Unity_Project`

새 개발 작업공간: `E:\task\KimchilyWebGL`

원본의 Unity 2022.3.16f1 프로젝트, APK, 게시 revision 및 게시 서버(8787)는 이 복제 작업에서 변경하지 않았다. 새 개발은 복제본의 Unity 6.3.24f1/WebGL 및 별도 게시 서버(8788)를 사용한다.

`source-manifest.json`에는 복사한 소스·설정·문서 2,148개의 크기와 SHA-256을 기록했다. Library/Temp/빌드 캐시, 게시 서버 토큰과 실행 상태는 복사하지 않았다. `.meta`와 자산 GUID, 로컬 UPM의 프로젝트 상대 배치는 유지했다.

`android-2022.3/`에는 당시 APK, EditMode 32/32와 Runtime PlayMode 90/90 결과, 실제 Android 이동·걷기·달리기·점프·카메라 화면과 검증 JSON을 보존했다. 이 결과는 원본 Android 버전의 기록이며 새 WebGL 버전의 검증 결과가 아니다.

원본 검증 보고서는 `docs/reports/2026-09-20-third-person-animation.md`, 모델/애니메이션 안내는 `docs/animation-import-guide.md`에 있다. 포트폴리오 정리 시 자체 개발한 UPM·TypeScript 실행기·모바일 입력·게시 도구와 예제에 사용한 외부 모델/라이브러리의 출처를 함께 설명할 수 있다.
