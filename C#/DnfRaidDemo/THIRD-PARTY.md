# 리소스와 도구 출처

데모의 바칼, 남귀검사 아바타·무기, 배경과 효과 이미지는 사용자의 로컬 던전앤파이터 설치본에서 읽어 PNG 변환·레이어 합성·프레임 선별한 자료다. 이미지와 관련 권리는 Neople 및 해당 권리자에게 있다. 이 프로젝트는 공식 게임·공식 배포물이 아니며 원본 이미지에 새로운 이용 허락을 부여하지 않는다.

클립 연결·재생 시간·발 기준점·배경 배치·전투 및 네트워크 규칙은 데모용으로 구성했다. 원본 NPK/PVF, 원본 게임 실행 파일, 원본 전투·서버 코드는 이 프로젝트에 포함하지 않는다.

개발 단계의 오프라인 이미지 추출에는 [HsOjo/PyDnfEx](https://github.com/HsOjo/PyDnfEx) commit `e417cefe43f54a40e20ef0df235aa1c8ecd8595a`(GPL-3.0)을 사용했다. 이 도구의 코드나 실행 파일은 Unity 프로젝트에 포함·링크하지 않으며 게임 실행에 Python이나 PyDnfEx가 필요하지 않다. 도구의 GPL과 원작 그래픽의 권리는 별개다. PNG 처리에는 Pillow를 사용했다.

사용자가 제작 목표와 검토 의견을 제공하고 AI 코딩 에이전트가 코드 작성·검증을 지원했다.
