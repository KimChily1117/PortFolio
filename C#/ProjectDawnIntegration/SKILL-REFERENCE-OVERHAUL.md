# 버서커 스킬 연출 재구성 · 2026-10-18

> 최신 적용: 진각성 컷신은 시전 후 3초(시연 영상 약 3.5초)부터 1.45초 동안 불투명하게 표시한다. 이전 반투명 배경 방식은 아래 이력으로만 보존한다.

사용자가 제공한 나무위키 저장 HTML과 동영상 23개를 기준으로 기존 스킬을 검토했다. 저장 페이지의 스크립트는 실행하지 않았다. DNF 설치 파일은 읽기 전용 자원 추출에만 사용했다.

## 반영한 내용

- 전체 21개 입력/스킬을 대조하고, 몸 애니메이션 13개를 단계별 프레임과 유지 시간으로 다시 연결했다. 기존에 검토한 idle 4프레임·프렌지 이도류·블러드 소드 손/혈검 연결을 보존했다.
- 크루얼은 세 번의 베기, 격노는 내려찍기→난무→검흔→피니시, 레이브는 흡입→큰 후려치기로 구분했다.
- 아웃레이지는 도약→착지→균열→후속 기둥, 스내치는 돌진 잡기→공중→내리꽂기로 구성했다. 두 도약의 실제 높이는 서버와 화면이 같은 함수를 사용한다. 지상 충격파는 피하지만 직격은 맞을 수 있다.
- 오버킬은 첫 입력으로 등 뒤 혈검을 65초 유지한다. 재입력 또는 유지 시간 만료 시 피니시와 지속 10타를 실행한다. 두 번째 입력에 MP를 중복 차감하지 않는다. 유지 중 다른 행동이 가능하며 사망하면 해제된다.
- 파멸은 6.7초의 연속 베기→도약/내려찍기→혈검 유지→뽑아 가르기→혈기 분출로 재구성했다. 전용 몸 48프레임을 단계별로 재생한다. 컷신은 시전자 본인에게만 보인다.
- 바닥 효과는 시전 위치와 돌진 거리 기준으로 고정하고, 몸의 후딜이 끝나거나 다음 스킬을 시작해도 이미 발생한 잔상이 끝까지 재생되도록 분리했다.
- 원본 궤적·바닥·기둥·등 뒤 혈검 등 자원 17개를 추가했다. 흡입선의 투명도를 바로잡고, 효과음도 변경된 타격 단계로 이동했다.
- **추가 사용자 요청으로 블러디 레이브(흡입/마무리)와 블러드 소드(혈검/폭발)의 검은 부분을 붉은 혈기로 변경했다.** 원본 아틀라스는 보존하고 로딩 시 색만 변환하며 투명도는 유지한다. 레이브 소용돌이는 가로·세로 각각 기존의 3배(1.1→3.3)로 확대하고 손 앞 중심에 맞췄다. 이것은 원작 복원 주장과 구분되는 사용자 지정 연출이다. 전투 판정 범위는 바꾸지 않았다.
- 일반 플레이에서는 플레이어 공격의 청록색 디버그 판정 도형을 숨겼다. F2 범위 확인 기능은 유지한다.
- **HTML에서 제목과 직접 연결된 아이콘 11개를 교체했다.** 프렌지, 폭주, 레이징 퓨리, 블러디 레이브, 블러드 소드, 아웃레이지, 오버킬, 블러드 붐, 블러드 리븐, 램펀트, 파멸이다. 원본 PNG와 설치본 해시를 비교했다. 저장 HTML에서 아이콘 칸이 비어 있는 스킬은 다른 아이콘으로 추측해 교체하지 않았다.

## 서버와 클라이언트

방장 Lua가 패턴을 계산하고 서버 C#이 검증·확정하는 구조를 유지한다. 오버킬 유지/피니시, 도약 시간은 공통 전투 상태에 포함되어 스냅샷과 서버 재실행으로 검증된다. 화면용 `ActionElapsed` 등을 임의 변경해도 도약 판정은 바뀌지 않는다. 피해 합계는 기존 데모의 공격 스킬 17개 모두 유지했다.

스냅샷 형식은 5, 콘텐츠 식별자는 `dawn-skill-reference-v5`다. 기존 버전과 섞지 말고 서버와 클라이언트 모두 새 빌드를 사용해야 한다. SQL 코디 저장·마을/레이드 외형 일치·로그인→마을→4인 매칭→레이드→복귀 흐름은 유지한다.

## 근거와 재현의 한계

영상의 공격 속도·장비·히트스톱·편집이 서로 다르다. 프렌지의 느린 영상, 오버킬의 임의 대기, 블러드 소드 두 번 시연을 한 번의 시전 시간으로 옮기지 않았다. 원작 ANI/SKL의 실제 프레임 시간·피벗·피해 공식은 복원하지 않았으며, 새 시간과 일부 자세 연결은 영상에 근거한 데모 재구성이다.

고어 크로스·블러드러스트·회피는 제공 페이지에 독립 동작 영상이 없다. 근거가 부족하거나 기존 연결을 유지해야 하는 몸 클립 6개는 보존했다. 원작과 모든 픽셀이 일치한다는 주장은 하지 않는다.

## 최신 수정 · 중간 시점의 불투명 진각성 컷신

사용자의 후속 요청에 따라 진각성 컷신을 불투명 화면 오버레이로 변경하고, 시전 후 3초에 영상 첫 프레임부터 재생한다. 시연 영상은 0.5초에 스킬을 시작하므로 영상 기준 약 3.5초부터 컷신이 표시된다. 원본 컷신 29프레임/20fps를 1.45초 동안 재생하고, 그동안 스킬·피해·네트워크 시간은 계속 진행한다. 컷신 종료 후 이미 진행 중인 스킬 단계로 자연스럽게 연결되며, 스킬을 다시 시작하지 않는다. 본인만 표시하는 조건과 1·2차 각성 연출은 유지한다.
