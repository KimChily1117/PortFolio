# v20 — 배경 낙하 전환과 전투 속도

## 사용자 최종 요청

2페이즈 전환의 캐릭터 낙하 부분을 보완하되, **낙하 중 캐릭터는 숨기고 배경만 빠르게 세로로 흐르게 한다. 기울임은 사용하지 않는다.** 새 전장 착지 시점부터 캐릭터를 표시한다. AWS 전원·배포는 변경하지 않는다.

## 전환 연출

| 공유 전환 시간 | 화면 |
|---|---|
| 0~6.7초 | 기존 인간형 확대·흑백 변신·불꽃 얼굴·암전 |
| 6.7~8초 | 원본 `bakal_2p_back.img` 성 배경을 위로 빠르게 스크롤. 캐릭터 숨김 |
| 8초 | 서버의 기존 전장 전환 경계에서 폐허 배경 공개 |
| 8~8.35초 | 새 전장만 표시 |
| 8.35초 | 현재 방 캐릭터 표시, 착지 모션·원본 FX·짧은 흔들림 |
| 9~10.6초 | 중앙 방 용형 보스 하강 |
| 10.6초 | 보스 착지 |
| 12초 | 전투 재개 |

주변 방은 해당 방 참가자만 표시한다. 중앙 방이 아닌 곳에 보스를 그리지 않는다. 9개 방 배경 변경, 방별 위치, 보호 시간, HP/공격 판정 경계는 유지한다. 캐릭터 표시 여부와 스크롤은 `PhaseTransitionStartTick`으로 계산하는 화면 표현이며 물리 위치를 수정하지 않는다.

원본 배경 프레임 4개를 추가해 총 10개 아틀라스·163프레임을 사용한다. 추출된 PNG SHA-256을 확인하고 패킹한다. 원본 ANI/카메라 스크립트를 복원한 것은 아니며 스크롤·착지 시간은 사용자 자료와 피드백에 맞춘 재구성이다.

## 전투 속도

| 항목 | 이전 | 현재 |
|---|---:|---:|
| 걷기 속도 | 4.8 | 5.5 (+14.6%) |
| 앞앞 달리기 | 7.2 | 8 (+11.1%) |
| 공격 중 이동 | 1.8 | 2.1 (+16.7%) |
| 일반 공격·일반 스킬 재생 | 장비 공격속도 | 장비 공격속도 × 1.12 |

모션만 빠르게 하는 방식이 아니다. 평타 쿨타임, 공격 잠금, 명중 시간, 스킬 이동과 화면 FX가 같은 `ActionRate`를 사용한다. 스킬 한 번의 피해와 일반 스킬 쿨타임은 유지한다. 평타 반복이 빨라져 초당 피해는 일부 증가한다. 일반 점프 물리, 보스 경고 시간, 각성 컷신은 그대로다.

`RaidActionTempo`는 방장 계산·서버 재실행·클라이언트 예측에 공유된다. 장비 공격속도와 곱해지며 각성은 기존 1배 시간축을 유지한다. 호환성 규칙은 `dawn-action-tempo-v20`, 스냅샷16, 레거시 UDP9. 서버와 클라이언트는 새 빌드 조합을 사용한다.

- 4인 동일 PC 지연 실행 `Artifacts/flow-4p-20261022-050103`: 방향별100±10ms 프록시, 전투26/26·전환7/7·로그인/마을/레이드/복귀10/10 통과. 이 실행은 전투 속도 변경 검증이며, 이후 추가된 캐릭터 숨김·붉은 운석 경고·카메라는 최종 빌드의 별도 화면 검증으로 확인한다. 외부4대 PC나 실제 키보드 수동 조작 검증은 아니다.
- 도중 재빌드는 종료 후 남아 있던 로컬 테스트 서버의 DLL 잠금으로 실패했다. 해당 테스트 포트의 소유 프로세스를 확인·종료한 뒤 재빌드했다. AWS와 무관한 로컬 빌드 잠금이었다.

## 추가 동적 연출 요청

- 첫 조우 시작의 확대는0.18초, 와인잔으로 들어가는 카메라는0.10초, 전체 구도로 복귀는0.12초. 확대 직후 짧게 오버슈트하고 멈춘다. 조우 장면과 전투 시작 시간은 유지한다.
- 메테오 본체는 실제 충돌 직전0.34초 동안 대각선으로 가속한다. 예고 시간은 유지하고, 화면의 운석 중심은 서버 충돌 시점에 정확히 목표 위치에 도착한다. 잔상과 빠른 폭발 재생을 추가한다.
- 현재 보고 있는 방에 낙하 예정 운석이 있을 때 붉은 비네트·짧은 안내가 표시된다. 아직 시작하지 않은 후속 운석이나 다른 방의 운석은 표시하지 않는다. 여러 운석의 경고 강도는 최대값으로 합성한다.
- 충돌 순간 카메라를 즉시 밀고0.22초 이내의 짧은 반동으로 정리한다. 배경과 캐릭터에 같은 충격을 반영한다. 실제 피해·점프 가능 시점은 바꾸지 않는다.
- `MeteorVisualChecks`는 다른 방/미시작 운석 배제, 정확한 충돌 위치,0.34초 가속 낙하, 충돌 전 카메라 흔들림 없음·0.22초 종료를 검증한다.

## 주요 코드

### 조우 BGM 후속 수정

조우 시작 시 1페이즈 BGM을 명시적으로 재생하고, 미리 로드해 첫 화면의 디스크 읽기 지연을 줄인다. 대기/로딩에서는 레이드 곡을 시작하지 않는다. 조우 동안 볼륨0.44, 일반 전투0.32로 이어지며 조우 종료 시 같은 곡을 재시작하지 않는다. 마을 음악과 중복되지 않도록 기존 음악을 멈춘다.

기존 일반 플레이에는 BGM 자동 재생이 있었지만, `--encounter-review`와 `--phase2-review`는 Update 조기 반환 때문에 음악 갱신을 생략했다. 두 시연 경로도 같은 음악 갱신 함수를 호출하도록 수정했다. 전투·서버 판정에는 변경이 없다. 이전에 전달한 무음 MP4 자체에는 소리가 새로 추가되지 않는다.
