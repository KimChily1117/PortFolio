## 플레이 방법과 조정값

- 플레이어의 평타·공격 스킬 피해를 v16 대비 **3배**로 높였다. 공통 전투 코어의 `PlayerDamageScale=3`이며 장비 물리 공격력·프렌지·폭주·무력화 배율을 그대로 곱한다. 적의 피해와 HP는 변경하지 않았다. 초기 +25% 조정은 사용자의 추가 요청에 따라 대체했다.
- **1 / 숫자패드1 / 화면 퀵슬롯 클릭**: 개인 회복 포션. 레이드마다 5개, 최대 HP의 40% 회복, 쿨타임 15초. 최대 HP를 넘지 않으며 가득 찬 상태에서는 소비하지 않는다. 포션은 이번 버전의 레이드 기본 지급품이며 DB 구매 아이템은 아니다.
- 사망·연결 해제·퇴장·전투 종료 상태는 사용 불가. 사망 시 기존 F5 공용 부활을 사용한다. 부활은 남은 포션/쿨타임을 초기화하지 않는다. 새 레이드만 5개로 시작한다.
- 보스·플레이어 체력이 줄면 실제 HP는 즉시 감소하고, 흰 잔상은 0.3초 유지 후 초당 최대 HP 55% 속도로 따라간다. 연속 피격 중에도 잔상이 계속 남아 멈추지 않게 했다. 회복은 새 체력으로 즉시 표시한다.
- 남은 HP 퍼센트는 보스 게이지, 본인 구슬, 파티 목록에 표시한다.

## 개인 콤보와 랭크

추출된 `dungeon_rank`, `dungeon_score`, `combo_bonus_num`, `newcombo_bonus`를 사용한다. 랭크 → 노란 누적 피해 → 흰 콤보 순서로 오른쪽에 표시한다. 콤보 숫자는 명중 시 최대 1.65배 확대 후 0.18초 동안 돌아온다. 랭크는 1280×800 기준 원본 픽셀 크기·비율이며 상승 시에만 최대 1.15배로 0.28초 팝업한다.

**원작 스타일 점수 공식을 복원한 시스템이 아니다.** 이 데모는 본인의 서버 확정 명중 횟수를 사용하며 노란 숫자는 실제 누적 피해다. 크리티컬·백어택 문구를 임의로 생성하지 않는다.

|---|---:|
| D | 1 |
| C | 3 |
| B | 6 |

마지막 확정 명중 이후 5초 동안 추가 명중이 없으면 콤보와 누적 피해를 초기화한다. 파티원 명중은 집계하지 않고, 타격 식별키로 중복 스냅샷을 제거한다. 다단 공격은 실제 피해 이벤트 수만큼 센다. 새 전투에서 집계를 초기화한다. 보상이나 서버 판정에 랭크를 사용하지 않는다.
