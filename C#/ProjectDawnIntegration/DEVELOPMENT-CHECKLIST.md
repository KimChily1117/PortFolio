# 남은 개발·이슈·친구 테스트 체크리스트

최신 흐름: [클리어 시네마틱·과반수 스킵](CLEAR-CINEMATIC-20261022.md). 서버 클리어 → 2초 암전 → 제공 영상 → ESC 과반수/자연 종료 → 보상창. 결과창의 ‘영수증 저장됨’ 문구 제거, 보스 HP가 전장 뒤에 가려지던 표시 순서 수정. AWS 변경 없음.

최신 로컬 변경: [v20 배경 낙하·전투 속도](PHASE2-FALL-TEMPO-20261022.md). 낙하 중 캐릭터 숨김, 배경 스크롤, 이동/일반 공격 속도를 개선했다. AWS는 정지 상태를 유지한다.

음원 후속 작업: [제공 MP4의 BGM 분할·실제 게임 오디오 녹음](BAKAL-SUPPLIED-BGM-20261022.md). 사용자 파일의 2:14를 기준으로 두 페이즈 음원을 교체했다. 검증 상태와 녹화 경로는 해당 기록을 따른다.

기준: **2026-10-22**, 로컬 v19 용 변신·폐허 전장·내려찍기 점프 안내와 마지막 AWS v15 배포/검증 기록. 로컬 소스·빌드는 변경했고, AWS 전원·배포본은 변경하지 않았다.

**현재 AWS는 사용자가 의도적으로 정지한 상태다.** 오늘 기존 주소의 게임/SSH 접속 시간 초과를 장애로 분류하지 않는다. 전원을 켠 뒤 현재 IP·인증서·서비스를 다시 확인한다. 10월18일 성공한 접속 시험을 오늘의 가동 상태로 표현하지 않는다.

예전 체크리스트에 섞여 있던 ‘AWS 미배포’, ‘TooLate 미수정’ 등의 과거 상태는 [이전 기록](Docs/DEVELOPMENT-CHECKLIST-before-20261022.md)에 보존했다. 아래 목록이 현재 우선순위다.

- [ ] **방장 이탈/무응답:** 방장 종료는 예정된 마을복귀인지 안내 확인. 소켓이 열린 채 응답이 멈추는 상황과 구분해 시험.
- [ ] **정상 난도 AWS 클리어:** 실제 장비·인장 지급→마을→재로그인→다른 PC에서 소유권 유지. 중복 지급/다른 사람 장비 노출0. 로컬 보상 fixture 성공으로 대체하지 않음.
- [ ] **30~60분 반복:** 여러 입장/귀환, 장시간 이펙트/오디오, 메모리·FPS·로그 크기 확인.
- [ ] **타격감 평가:** 내 공격의 접촉/강약/마무리, 타인 효과에 묻힘, 바닥 경고 가독성, 피로도/화면 흔들림을 각각 평가.

진행 불가 오류나 반복 강제 복귀가 나오면 이후 항목보다 해당 재현을 먼저 기록한다. 타격감은 가능하면 본인 화면+게임 소리를 짧게 녹화한다. 친구에게는 ‘타격감 어때?’ 하나만 묻기보다 접촉감/강약/소리/가독성 네 항목을 각각 묻는다.

보고 양식:

```text
빌드 ZIP 이름:
발생 시각(KST):
인원 / 방장 또는 참가자 / 레이드 방 번호:
직전 행동과 재현 순서:
기대했던 결과 / 실제 결과:
반복 횟수:
가능하면 소리 포함 짧은 영상:
Player.log 사본:
```

실제 플레이 로그: `%USERPROFILE%/AppData/LocalLow/Local Prototype/ProjectDawn 4P Raid/Player.log`. 게임을 다시 켜기 전에 사본을 보관한다. 비밀번호·SSH 키·DB 접속 파일은 받거나 공유하지 않는다.
