## 2. 원하던 Lua 콘텐츠 제작 흐름 확장

- [x] **선택 콜백에서 행동 조합으로 확장.** 접근·준비·공격/4연속 메테오·방 이동용 표식을 Lua에서 제안하고 C#이 행동 수·대상·간격을 검증한다. 일반 패턴 세부 판정과 피해/범위는 C#에 유지한다. [구현 설명](LUA-ROOMS-HUD-INTEGRATION.md).
