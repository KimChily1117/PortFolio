# 검증 결과와 한계

## 2026-10-22 공개 소스 검증

이 폴더에서 원본 리소스·실제 계정·DB 백업 없이 검사했습니다.

| 항목 | 결과 |
|---|---|
| Client + Protocol + 공통 코어 Release 빌드 | 성공, 오류 0·경고 0 |
| FlowHost / .NET 10 / DawnCloud=true | 성공, 오류 0. 기존 migration 명명 2건·미사용 필드 1건 경고 |
| CloudGateway Release 빌드 | 성공, 오류 0·경고 0 |
| 전투 원장·재판정·확정 | 26/26 |
| 커스텀 커맨드 | 30/30 |
| Lua 패턴·서버 검증 | 50/50 |
| 3×3 방·메테오·불바다 | 72/72 |

총 178개 콘솔 검사입니다. Lua 검사는 고정 버전 NuGet MoonSharp로 실행했습니다. 테스트 타깃 net8.0, 실제 런타임 .NET 10.0.13(Major roll-forward)입니다. 이 결과가 Unity 전체 화면·실제 DB·인터넷 플레이를 새로 검증한 것을 뜻하지 않습니다.

초기 검사는 도구 실행 환경의 NuGet TLS와 재사용 MSBuild 노드 경로 오류로 실패했습니다. 정상 사용자 환경과 `--disable-build-servers -m:1`로 재실행한 최종 결과입니다. 게임 전투 규칙은 변경하지 않았습니다.

## 최신 게임 실행 기록

AWS v21, 정상 보스 HP 32,500, 4개 독립 Unity 프로세스로 마을 채팅 → 순차 매칭 → 1/2페이즈 → 클리어 시네마틱 → 보상 → 실제 MySQL 장비 저장·장착을 확인했습니다.

- 기능 흐름 44/44, Unity 오류 0.
- 방장 Lua 제안 18개 서버 확정.
- 네 캐릭터의 보상 아이템 소유와 Equipped 0 → 1을 실제 SQL 재조회.
- **TooLate 14건 재관측.** 입력 나이가 허용치 약 82ms보다 0.075~5.649ms 높았습니다. 네 클라이언트의 중복 수신을 56건으로 더하지 않습니다.
- 한 Windows PC → AWS 공개 TLS 시험. 서로 다른 PC/ISP나 물리 키보드·한글 IME 시험이 아닙니다.
