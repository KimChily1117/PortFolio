# 원작 스킬 연출 대조 자료 준비

## 가장 도움이 되는 자료

**원작 PC 던파에서 직접 촬영한 원본 MP4**가 우선이다. 60fps 이상, 원본 해상도, 게임 소리 포함, 슬로모션 편집이나 프레임 보간 없이 보내면 된다. 게임 안 훈련용 표적을 사용할 수 있다면 고정된 표적으로 촬영한다. GIF는 소리가 없어 보조 자료로 쓴다.

이번 우선순위는 평타 → 프렌지 이도류 평타 → 블러드 소드 → 익스트림 오버킬이다.

| 자료 | 촬영 내용 | 확인할 것 |
|---|---|---|
| 평타 | 일반 상태의 한 타씩, 이어지는 전체 콤보, 좌/우 방향 | 각 타격 프레임·회수·검의 궤적·후딜 |
| 프렌지 | 버프 시전 → 대기 → 전체 이도류 콤보, 대시 평타 별도 | 보조 검의 위치·겹침 순서·콤보 강약 |
| 블러드 소드 | 준비부터 찌르기·폭발·회복까지 | 검 생성·찌르기 접촉·폭발·소리 시점 |
| 오버킬 | 최초 시전/혈검 유지 → 재입력 마무리 전체 | 첫 충돌·지속 폭풍·마지막 타격·잔상 |
| 공통 | 같은 조건으로 명중 3회 / 빗맞힘 3회 | 기본 시전음과 명중 시 추가되는 소리·히트스톱 분리 |

한 번에 여러 스킬을 겹치기보다 각 스킬 앞뒤로 약 1초씩 대기한다. 화면은 캐릭터부터 이펙트 끝부분까지 잘리지 않게 담고, BGM은 끄되 효과음·보이스는 켠다. 파티원 이펙트나 데미지 숫자가 가리면 별도 영상도 좋다.

## 영상과 함께 적어줄 정보

```text
촬영 날짜 / PC 던파 지역·버전:
스킬명 / 스킬 레벨 / 각성·변형·강화 선택:
공격속도 수치 / 무기 종류 / 관련 장비·버프:
해상도 / 녹화 FPS / 게임 이펙트 투명도:
일반·프렌지 상태 / 명중·빗맞힘:
특히 맞추고 싶은 구간: 예) 00:02.10~00:02.45 검 끝과 폭발
```

## 다른 자료의 역할

- 이미 전달한 나무위키 HTML과 `_files` 폴더: 움직이는 원본 GIF/MP4, 아이콘, 형태를 나란히 비교하는 기준으로 사용한다. 스크린샷만으로는 타이밍이나 소리를 맞출 수 없다.
- 공식 자료 예시: [Neople DFO 진 버서커 소개](https://www.dfoneople.com/news/updates/1682/SLAYER%28M%29-NEO%3A-AWAKENING/NEO%3A-BERSERKER). 스킬 설명·이미지의 보조 출처다. 한국 PC판의 목표 버전과 같은 연출인지 별도 대조하며, 이 과거 업데이트 페이지를 현재 한국판의 정확한 시간표로 사용하지 않는다.
- 기존 추출 스프라이트: IMG/NPK 경로, 프레임 번호·순서, 캔버스 크기, 발/손 기준점, 뒤·앞 레이어 구분이 있으면 영상과 대조하기 쉽다. 원본 음원 이름과 대응 스킬도 도움이 된다.
- 원본 ANI 시간표가 실제로 확보된 경우 함께 대조한다. 현재 프로젝트의 추정 타이밍을 원본 ANI 복원 결과로 부르지 않는다. 원본 게임의 서버 코드·패킷 구조를 확보했다고 가정하지 않는다.

## 재현 방법과 범위

1. 목표 버전·장비 조건을 하나로 정한다.
2. 영상에서 준비/접촉/정지/폭발/회복의 프레임을 표시한다.
3. 기존 스프라이트의 프레임 순서·기준점·레이어를 연결한다.
4. 스킬 이펙트·오디오 파형의 시작점을 맞춘다.
5. 원작/데모를 같은 배율로 나란히 보여주고 차이를 다시 조정한다.

자료가 충분하면 시각·청각 표현을 매우 가깝게 재현할 수 있다. **영상만으로 원작 내부 코드를 1:1 복원하거나 완전히 동일한 동작을 보장할 수는 없다.** 현재의 방장 계산·서버 검증 구조는 유지하며, 원작과의 유사성은 실제 대조 자료로 확인한다.
