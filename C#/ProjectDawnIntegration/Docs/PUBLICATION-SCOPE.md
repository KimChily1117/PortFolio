# 공개 범위·출처

## 이 폴더에 포함한 것

직접 작성·통합한 C#·Lua·Protobuf·Python·PowerShell·SQL 스키마·검사 코드, 작성한 Unity 씬·프로젝트 설정, 기술·인수인계 문서입니다. 실제 전투 규칙은 개발본과 유지하며, 공개본에서 외부 DLL 참조를 고정 버전 NuGet 복원으로 바꿨습니다.

## 제외한 것

- DNF 원본/추출 스프라이트, 텍스처, 폰트, 오디오, 영상, NPK/IMG, 원본 기반 데이터 카탈로그.
- Resources·StreamingAssets·Data, 리소스 추출 작업 디렉터리.
- 게임 실행 파일, 빌드 산출물, NuGet/Unity DLL, 캐시, 운영 로그·시연 원본·DB 백업.
- 실제 계정/비밀번호, 초대키, SSH/TLS 개인키·인증서, 클라우드 인스턴스/접속 설정, SQL 실행 데이터.
- 특정 운영 VM을 대상으로 작성된 배포·DB 조회 자동화 파일.

문서의 운영 IP·인스턴스 식별자는 예시 값으로 바꿨습니다. 인증 검사용 임시 문자열과 런타임 비밀 생성 코드는 실제 계정 정보와 구분합니다.

## 자원과 의존성

원작 게임 자원의 권리는 원권리자에게 있으며, 이 폴더는 해당 자원을 재배포하지 않습니다. 시각 분석·참고와 직접 구현한 게임 로직을 구분합니다. 원작 서버 소스·전체 공식·ANI 시간표를 복원했다고 주장하지 않습니다.

MoonSharp·Google.Protobuf 등은 각 패키지 라이선스를 따릅니다. MoonSharp의 원래 고지문은 [LICENSE](../ThirdParty/MoonSharp/LICENSE-MoonSharp.txt)에 보존했습니다.

## 기여 표현

개인 프로젝트이며 요구사항·전투 기획·표현 기준과 반복 피드백을 통해 개발 방향을 정했습니다. Codex·Claude Code를 분석·소스 수정·검사·빌드·문서화 보조로 활용했습니다. 면접에서는 공통 전투 코어, Lua 제안 검증, 시각 보정·재판정, 보상 영속화의 책임과 실패 사례를 실제 코드로 설명하는 것을 목표로 합니다.

기존 저장소의 다른 프로젝트와 과거 커밋은 이 공개본 필터 범위에 포함하지 않습니다. 과거 자원 이력 삭제나 Git history 재작성은 수행하지 않았습니다.
