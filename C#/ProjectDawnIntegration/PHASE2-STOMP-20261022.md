# v19 — 용 변신·폐허 전장·내려찍기 점프 안내

후속 변경: [v20 배경 낙하·전투 속도](PHASE2-FALL-TEMPO-20261022.md). 아래는 v19 구현 기록이며, 최신 낙하 표현과 속도·호환 규칙은 후속 문서를 따른다.

사용자 제공 2페이즈 영상에 맞춰 인간형 확대 → 흑백 변신 → 불꽃 용 얼굴 → 암전 → 폐허 전장 → 용형 하강·착지를 연결한다. AWS 전원·배포는 변경하지 않는다. 개발 빌드 전체를 함께 사용해야 한다.

## 전환과 서버 권위

| 서버 공유 경과 | 화면/상태 |
|---|---|
| 0~2초 | 기존 전장 어두워짐, 인간형 준비 |
| 2~4.3초 | 플래시, 붉은 배경 이동, 확대, 흑백 얼굴 |
| 4.3~6초 | 흰 가지 형태와 불꽃 용 얼굴 |
| 6~8초 | 암전 |
| 8초 / 480틱 | 폐허 중앙 전장으로 변경, 플레이어 착지 표현 |
| 9~10.6초 | 줌아웃에서 전투 카메라로 복귀하며 용형 바칼이 아래로 가속, 낙하 잔선 |
| 10.6초 / 636틱 | 발 착지·원본 FX·소리·카메라 흔들림 |
| 12초 / 720틱 | 조작과 전투 재개 |

방장 계산·서버 C# 검증은 유지한다. `PhaseTransitionStartTick`이 스냅샷에 포함되어 재접속/재판정도 동일 시간축을 따른다. 연출 중 네트워크 틱은 진행하지만 피해·이동·스킬·전투 제한시간은 멈춘다. 기존 방 불장판과 표식은 남은 시간을 유지한다. 진행 공격/입력 버퍼는 취소하여 종료 직후 갑자기 스킬이 나오지 않는다. 방 이동 구조와 방별 위치는 유지하며 중앙과 주변8개 방 전체가 폐허 스프라이트로 바뀐다. 현재9개 방은 공통 폐허 배경을 사용하며 서로 다른 방 지형을 새로 설계한 것은 아니다. 캐릭터의 연출상 낙하는 물리 위치 이동이나 넉백 판정이 아니다.

1페이즈 HP는 50% 경계에서 멈춰 강한 다단히트가 변신을 건너뛰지 않는다. 진행 중 보호 대상 메테오·돌진 연속 공격을 마친 뒤 전환한다. 새 규칙 `dawn-dragon-transition-v19`, 스냅샷16, 레거시 UDP8.

## 타격 수치와 내려찍기

- 플레이어 피해 배율3 → **1.5**, 직전 빌드 대비 절반. 장비·버프·스킬별 배율은 그대로다.
- 보스 Y 피격 반경0.45 → **0.8**. X 반경0.75는 유지한다. 더 넓어진 상하 거리에서 공격이 닿지만 무한 범위가 아니다.
- 지면 충격파3회: 예고0.9초, 판정0.14초, 간격1.3초를 유지한다. 원이 약85% 찼을 때 점프하면 판정 시 필요한 높이에 도달한다.
- 인간형 원본49~59프레임(57번 착지), 용형110~119프레임(117번 착지)을 사용한다. 예고 때 발을 들고,100%에 발이 닿도록 모션을 연결했다.
- 원은 앞쪽 발이 닿는 위치를 기준으로 안→밖으로 채운다. 경고 원은 공격 범위 축소가 아닌 타이밍 안내이며, 충격파 판정은 전장 전체다.
- 원본 `jumpwarning_200.img`의 날개+위쪽 화살표를 원 안에 표시한다. 기본 금색,85%부터 흰색 강조. 상태별 색 선택은 데모 설계다.
- 내려찍기 소리는 `StompImpact`의 화면 판정 시점에 재생한다. 서버 확정 후 같은 소리를 중복 재생하지 않는다. 운석 낙하 충격파와 보스의 내려찍기는 별도 패턴으로 유지한다.
- 첫 조우 유리 파편은 사용자 추가 요청에 따라 완전 불투명하게 표시한다. 원본의 검정 바깥 배경만 제거하고 내부 구멍을 메운 마스크로 원본의 어두운 용 얼굴 RGB를 보존한다. 이전 알파1.85배 근사는 최종 상태가 아니다.
- 운석 직격은 붉은 타원으로 중심→바깥 채움. 직격 판정도 `Ellipse`로 변경하여 표시 밖 사각 모서리에서 맞지 않는다. 기존 반경3.3/1.2는 유지한다.
- 점프로 피할 수 있는 운석 충격파에는 본인 발밑에 차오르는 타원과 원본 점프 날개를 표시한다.85%부터 흰색. 직격 범위 안이면 먼저 이동하라는 붉은 안내가 나온다. 직격/방 운석은 점프만으로 피하지 못하고, 방 불장판의 전체방 피해도 그대로다.
