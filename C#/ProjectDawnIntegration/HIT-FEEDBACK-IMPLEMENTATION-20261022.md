# 개인 타격감 1차 구현 · v16

2026-10-22. **로컬 소스·Windows 빌드만 변경했다. AWS는 켜거나 배포하지 않았다.** AWS의 마지막 배포는 v15다.

## 구현 내용

| 공격 | 접촉 시 정지 요청 | 연출 |
|---|---:|---|
| 일반 평타 | 50ms, 마지막 타 65ms | 짧은 방향성 반동, 작은 접촉광, 실제 공격자의 무기 타격음 |
| 프렌지 평타 | 42ms, 마지막 타 65ms | 연타 리듬 유지, 마지막 타의 광량·반동 강화 |
| 블러드 소드 | 90ms | 찌르기 접촉에 원본 폭발음, 큰 붉은 접촉광·감쇠 반동 |
| 오버킬 첫 명중 | 105ms | 가장 강한 반동·접촉광, 원본 마무리 음원 |
| 오버킬 지속 타격 | 8ms | 낮은 음량과 작은 반동, 매 타격에 큰 폭발을 반복하지 않음 |
| 오버킬 마지막 접촉 | 최대 60ms | 접촉광·반동 강화. 이미 다른 동작/대기/점프로 넘어갔다면 몸을 정지시키지 않음 |

- 1초 내 정지 요청 합계 240ms 상한, 80ms 내 재정지 제한, 이후 75ms 동안 현재 동작 시간으로 복귀한다.
- 같은 액션의 몸·무기·스킬 FX 시계를 함께 조절한다. 다음 액션, 점프, 피격, 사망, 방 전환은 이전 접촉의 정지에 붙잡히지 않는다. 위 수치는 요청 상한이며 실제 화면 정지 길이는 취소·액션 종료에 따라 짧아질 수 있다.
- 실제 위치·점프 높이·스킬 도약 높이·보스 예고·피해·쿨타임·서버 시계는 계속 진행한다. `Time.timeScale`은 변경하지 않는다.
- 기존 스프라이트·혈기 FX를 유지하고 **원본 공통 명중 FX를 추가**했다. 사용자 방송 영상 피드백 이후 `slashlarge1~3`, `knocklarge`, `unionhit`로 작은 임시 십자광을 교체했다. 합성·크기·시간은 데모의 연출 설계이며 원작 ANI 복원 결과로 부르지 않는다.
- 본인 전용 음원 채널 3개, 우선순위 16, 공격자별 발음 제한을 사용한다. 원본 타격 음원을 미리 로드하며 큰 접촉음은 0.92배 피치, BGM은 접촉 시 0.32→0.23으로 짧게 낮춘다.
- 블러드 소드/오버킬의 본인 강한 접촉음은 고정 시전 타이머 대신 명중 이벤트에서 재생한다. 빗맞히면 그 명중 강조음은 생략된다. 준비음·보이스는 유지한다.
- 예측 후 확정 이벤트가 같은 키로 돌아오면 연출·소리를 다시 재생하지 않는다.

## 권위와 버전

방장 계산 → 서버 C# 검증·확정 구조는 유지한다. `CombatEvent`에 스킬, 소스 액션, 타격 번호, 방향, 콤보, 프렌지 여부, 접촉 동작 시간을 담아 지연 도착 시 다음 액션과 혼동하지 않게 했다. 개인 피드백 클래스는 네트워크 송신이나 전투 상태 변경을 하지 않는다.

- 규칙 ID: `dawn-personal-impact-v16`
- 스냅샷: 13 (이전 12는 명확하게 거절)
- **v16 클라이언트와 v15 AWS 서버를 섞어 친구에게 전달하지 않는다.** 이후 사용자가 AWS 재개를 요청할 때 서버·클라이언트를 함께 갱신해야 한다.

자동 검사가 타격감의 주관적 만족도나 원작과의 일치를 증명하지는 않는다. 다른 무기들의 음색·본인과 파티 소리 균형·반동 강도는 직접 조작하면서 다음 조정 의견을 받는다. 현재 캡처 영상은 무음이다.

## 추가 영상 피드백: 큰 명중 FX·데미지 숫자

사용자가 제공한 11.9초 방송 녹화는 큰 흰 코어/청색·자홍 잔광, 우측 콤보·랭크 갱신, 큰 흰 피해 숫자를 보여준다. 60fps 파일이지만 반복 프레임이 있어 정지 시간을 그대로 히트스톱 값으로 사용하지 않았다. 관찰 보고서 (`Artifacts/hit-reference-video-20261022/VIDEO-REFERENCE-ANALYSIS.md`, 로컬 검증 자료).

REA 6.5.0의 `open_binary`는 해당 NPK를 `unsupported binary format`으로 거절했다. 원본 설치를 변경하지 않고 기존 PyDnfEx로 디코딩했다. 이를 REA가 원작 코드를 디컴파일한 결과라고 부르지 않는다. 도구 결과 (`Artifacts/hit-reference-video-20261022/rea-open-result.json`, 로컬 검증 자료)와 리소스 보고서 (`Artifacts/hit-resource-reference-20261022/RESOURCE-FINDINGS.md`, 로컬 검증 자료)에 한계·SHA256·원본 경로·프레임을 보존했다.

- 총 조사/추출: 8 NPK, 43 IMG, 954 PNG. 그 중 공통 접촉 FX5종과 피해 폰트20글리프를 Unity에 수입했다.
- `damagefont00.img`의 0~9 흰 숫자와 40~49 붉은 피격 숫자를 사용한다. 본인 피해는 2.45배(큰 피해 2.8배), 첫 120ms는 최대1.32배 추가 확대 후 떠오르며 사라진다. 파티원 피해 숫자는 1.4배로 구분한다. 이는 화면 배율이며 피해량 배율이 아니다.
- 피해 숫자는 Dawn의 **서버 확정 이벤트**에서만 그린다. 예측 접촉광/소리가 취소돼도 존재하지 않는 피해 수치를 보여주지 않는다.
- 영상의 정확한 피해 숫자 스킨은 미확정이다. 이번에는 원본 기본 흰 폰트를 사용했다.
- **콤보/SSS/점수/BackAttack/Critical 리소스는 확보했지만 랭크·스타일 점수 시스템은 아직 구현하지 않았다.** 원작 공식·임계값·판정 조건을 이미지에서 추정해 원작과 동일하다고 주장하지 않는다. 실제 크리티컬/백어택 계산 없이 해당 문구를 임의 표시하지 않는다.
- 재추출/수입: `python Tools/ImportHitFeedback.py`. 프레임 출처는 `Tools/hit-feedback-asset-provenance.json`.
