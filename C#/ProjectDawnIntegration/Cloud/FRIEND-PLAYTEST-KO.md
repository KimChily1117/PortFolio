# ProjectDawn 친구 테스트 안내

모두 같은 ZIP을 사용합니다. **게임 계정을 가입하고 그 계정 아래에 캐릭터를 만드는 방식**입니다. AWS 계정이나 초대 키는 필요하지 않습니다.

## 시작하기

1. ZIP 전체를 압축 해제하고 `Start-ProjectDawn.cmd`를 실행합니다. exe만 따로 옮기지 않습니다. Unity/MySQL 설치는 필요하지 않습니다.
2. 처음이면 **회원가입**을 선택합니다. 아이디는 영문·숫자·밑줄·하이픈 3~32자, 비밀번호는 8~128자입니다. 아이디 대소문자는 구분하지 않습니다.
3. 가입한 아이디와 비밀번호로 로그인합니다.
4. 캐릭터를 선택하거나 새 닉네임으로 생성합니다. 계정당 최대 4개이며 닉네임은 서버 전체에서 중복될 수 없습니다.
5. 마을에서 채널을 선택하고 던전 입구에서 **1~4인** 중 입장 인원을 선택합니다. 1인은 혼자 입장, 2~4인은 같은 인원을 선택한 사람들이 해당 수만큼 모이면 시작합니다. 기본값은 4인입니다.

친구끼리는 동일한 입장 인원을 선택하세요. 보스 체력·피해량은 기존 4인 기준으로 유지되므로 소수 인원은 더 어렵습니다. 현재 버전은 `dawn-reentry-revive-v15`이며 이전 ZIP은 새 ZIP으로 교체해야 합니다.

## 공용 부활

- 레이드당 파티 전체가 **3회**를 공유합니다. 사망하면 **F5** 또는 화면의 **부활** 버튼으로 최대 체력 **50%**로 돌아옵니다.
- 부활 후 **3초 무적**이 적용됩니다. 스킬 쿨타임·MP·현재 방은 유지됩니다.
- 전원 사망했을 때도 횟수가 남으면 **10초 안에** 부활할 수 있습니다. 횟수가 없거나 시간이 지나면 패배하고 마을로 복귀합니다.
- 부활은 서버 확정 뒤 적용됩니다. 같은 마지막 1회를 여러 사람이 동시에 사용하면 한 명에게만 적용됩니다.

다른 PC에서도 같은 게임 계정으로 로그인하면 저장된 캐릭터를 불러옵니다. 장비·코디·보상은 각 캐릭터에 연결됩니다. 같은 계정의 동시 접속은 제한됩니다. 비밀번호는 실행 파일이나 접속 파일에 저장되지 않습니다.

## 채팅

- **Enter**로 입력창을 열고, 다시 **Enter** 또는 **전송** 버튼으로 보냅니다. **Esc**는 입력 취소입니다.
- 전송된 내용은 캐릭터 위에 말풍선으로 약5초간 표시됩니다. 같은 사람이 다시 보내면 최신 내용으로 교체하며, 다른 내부 방의 파티원 메시지는 채팅창에서 확인합니다.
- 마을에서는 같은 채널의 사람들과 대화합니다. 던전에서는 같은 레이드 파티 전체와 대화하며, 내부 3×3 방이 달라도 함께 사용합니다.
- 채널/던전 전환 시 이전 대화는 지웁니다. 다른 채널·다른 파티·마을과 던전 사이에는 전달하지 않습니다.
- 한 줄 120자 이내, 초당 1회 전송입니다. 채팅 입력 중 이동/공격 단축키는 막지만 전투와 피격은 계속됩니다.
- 서버에 대화 이력을 저장하지 않습니다. 비밀번호 등 개인 정보를 보내지 마세요.

## 접속 문제와 문의

- ‘테스트 서버를 준비 중입니다’가 나오면 아직 운영 주소가 들어 있지 않은 준비본입니다. 운영자가 서버를 연 뒤 배포한 버전을 사용하세요.
- 비밀번호 오류는 아이디와 비밀번호를 다시 확인하세요. 요청이 많다는 메시지가 나오면 잠시 기다려 주세요.
- 회원가입은 한 IP에서 시간당 4회까지, 테스트 서버 전체는 기본 64계정으로 제한됩니다. 같은 공유기에서 가입할 때는 제한이 합산됩니다.
- 인증서 오류가 나오면 우회하지 말고 운영자에게 알려주세요.
- 자동 비밀번호 찾기는 이번 테스트 버전에 없습니다. 가입 정보를 잊었다면 운영자에게 문의하세요. **비밀번호를 채팅으로 보내지 마세요.**
- 오류 문구·발생 시각·장면을 전달하고 비밀번호가 포함된 화면은 보내지 마세요.

## Enter 전송 수정판 · 2026-10-18

입력창을 연 뒤 다시 Enter를 눌러 전송하는 경로를 수정했습니다. 입력창의 GUI 키 이벤트를 직접 처리하고, 한글 조합 중 전송 요청은 마지막 글자가 확정된 뒤 처리합니다. 새 ZIP을 전체 압축 해제한 뒤 `Start-ProjectDawn.cmd`로 실행하세요.

## 함께 확인할 내용

- 로그인 → 채널/마을 → 1~4인 선택 매칭 → 레이드 → 보상 → 마을 복귀
- 재로그인 및 다른 PC에서 캐릭터·장비·코디 유지
- 메테오 예고를 보고 점프한 결과, 방 이동, 두 명 표식과 불바다, 3회 돌진 동기화
- 진각성 컷신은 시전자에게만 표시되고 파티원에게는 전투 연출이 계속 보이는지
- 비방장 연결 중단 후 3분 이내 복귀, 방장 이탈 시 전투 중단/마을 복귀

친구 서버는 별도의 테스트 DB를 사용하며 개발 PC의 기존 데이터는 자동 이전되지 않습니다. 서버 운영 시간에만 접속할 수 있습니다. 2026-10-18 개발 PC의 Unity 네 프로세스가 실제 AWS 공인 TLS 서버에서 전투·마을 왕복 검사를 통과했습니다. 서로 다른 친구 PC와 회선에서는 이번에 함께 확인합니다. 최초 실행의 방장 제안 지연 종료 기록이 있어 장시간 안정성 검증은 계속 필요합니다.

현재 v14 빌드는 1인·2인·4인 AWS 입장/채팅/말풍선/복귀 검사를 통과했고, 4인 전투26개·흐름10개 검사도 통과했습니다. 3인에서는 동일 지연 입력1건이 거절되어 전체17개 중16개만 통과했습니다. 이전 채팅 v13 빌드의 지연 입력6건 기록도 보존했습니다. 지연 문제의 근본 원인은 아직 해결됐다고 판단하지 않으며, 친구 PC·다른 회선·장시간 시험이 필요합니다. 자동 시험은 실제 키보드/한글 IME 조작과 구분합니다.
